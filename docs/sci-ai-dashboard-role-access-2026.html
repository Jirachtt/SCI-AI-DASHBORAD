สิทธิ์เขียนข้อมูล (Firestore)

Student / General: อ่านอย่างเดียว
Admin: users / roles / approval เท่านั้น

AI DATA SCOPE

Dean: internal data ทุก domain
Chair / Staff: ตาม section ที่ได้รับสิทธิ์
Student: academic-safe / aggregate
General: public + low-risk
Admin: ไม่มี internal dashboard AI

ข้อควรรู้ด้านความปลอดภัย

UI/AI permission กับ Firestore read rule เป็นคนละชั้น ปัจจุบัน firestore.rules อนุญาตให้ผู้ใช้ที่ sign-in อ่าน shared dataset documents ได้ แต่หน้าเว็บและ AI ยังบังคับสิทธิ์ตาม role หากต้องการแยกข้อมูลระดับ field/PDPA อย่างเข้มงวด ควรเพิ่มกฎ backend ให้ละเอียดขึ้น

Security flow: Login → Normalize Role → Filter Routes → AI Context Guard → Data Trust Check → Write → Audit Log  |  Settings / profile ใช้ได้กับผู้ใช้ที่ sign-in แล้ว
